## Publish a post with one file

Add a Markdown file to the project-level `post` directory and it will appear in the blog automatically.

### Frontmatter format

```md
---
title: Post title
date: 2026-07-22
category: Development
tags: [React, Retrospective]
description: A short summary shown in the post list.
---
```

Write the rest of the article with standard Markdown. Categories and tags are automatically added to the filters.
